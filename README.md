# Student_performance_analysis
A Data Science project to analyze student marks, attendance and academic performance using python.
Student Performance Analysis

Project Overview

Student Performance Analysis is a beginner-friendly Data Science project developed using Python. It analyses students' academic performance based on subject marks and attendance.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Project Features

- Created a student dataset.
- Calculated total and average marks.
- Identified the topper and lowest scorer.
- Analysed class average marks.
- Created student performance bar charts.
- Compared subject-wise average marks.
- Analysed attendance and academic performance.
- Created a correlation heatmap.

Visualizations

- Student-wise performance chart
- Subject-wise average chart
- Attendance vs average marks scatter plot
- Correlation heatmap

Key Findings

- Identified students with the highest and lowest total marks.
- Compared average performance across subjects.
- Found a strong positive correlation between attendance and average marks in the sample dataset.

How to Run

1. Download the ".ipynb" notebook.
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Run the cells one by one.
